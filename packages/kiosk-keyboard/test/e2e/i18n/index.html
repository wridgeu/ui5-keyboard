KioskKeyboard i18n Extensibility Demo

1. Baseline (no customization)

The keyboard renders with the library's built-in English labels. Shift, Enter, Backspace, and Space use the default translations. The root element has aria-label="Virtual Keyboard".

2. New language via resolver (French)

Adds French translations using setI18nResolver with a lookup map. All key labels and ARIA attributes update to French. Keys not in the map fall through to the base bundle text. 

KioskKeyboard.setI18nResolver((key) => frenchTexts[key]);

3. Override existing English labels via resolver

Replaces specific English labels with custom wording: "Enter" → "Go", "Backspace" → "Delete", and the root label becomes "Touch Keyboard". Keys not in the override map keep their base text. 

KioskKeyboard.setI18nResolver((key) => overrideTexts[key]);

4. Programmatic resolver with transformation

Uses setI18nResolver to dynamically transform text at runtime. The resolver receives the key, locale, and base-bundle resolved text, and can return a replacement string. Here it uppercases all special-key labels and adds an emoji prefix to the keyboard label. 

KioskKeyboard.setI18nResolver((key, _locale, resolvedText) => {
  if (key === "KIOSK_KEYBOARD_LABEL") {
    return "\u2328\uFE0F " + resolvedText;
  }
  if (key.startsWith("KEY_")) {
    return resolvedText.toUpperCase();
  }
});
