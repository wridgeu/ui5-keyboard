KioskKeyboard i18n Extensibility Demo

1. Baseline (no customization)

The keyboard renders with the library's built-in English labels. Shift, Enter, Backspace, and Space use the default translations. The root element has aria-label="Virtual Keyboard".

2. New language via enhancement bundle (French)

Adds French translations using configureI18n with a bundleUrl pointing to a local .properties file. All key labels and ARIA attributes update to French. 

KioskKeyboard.configureI18n({
  enhanceWith: [{
    bundleUrl: "./i18n/messagebundle.properties",
    supportedLocales: [""],
    fallbackLocale: ""
  }]
});

3. Override existing English labels via enhancement bundle

Replaces specific English labels with custom wording: "Enter" → "Go", "Backspace" → "Delete", and the root label becomes "Touch Keyboard". Keys not in the override bundle keep their base text. 

KioskKeyboard.configureI18n({
  enhanceWith: [{
    bundleUrl: "./i18n-override/messagebundle.properties",
    supportedLocales: [""],
    fallbackLocale: ""
  }]
});

4. Programmatic override hook

Uses setI18nOverrideHook to dynamically replace text at runtime. The hook receives context (key, locale, resolved text) and can return a replacement string per key. Here it uppercases all special-key labels and adds an emoji prefix to the keyboard label. 

KioskKeyboard.setI18nOverrideHook((ctx) => {
  if (ctx.key === "KIOSK_KEYBOARD_LABEL") {
    return `⌨️ ${ctx.resolvedText}`;
  }
  if (ctx.key.startsWith("KEY_")) {
    return ctx.resolvedText.toUpperCase();
  }
});
